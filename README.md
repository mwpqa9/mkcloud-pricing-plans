## 先弄清楚：Mkcloud 卖的不是普通 VPS

Mkcloud 是 2023 年成立的国人商家，主营合规跨境专线服务器，产品形态是 IEPL、IPLC、IX 三类专线线路，覆盖广港、深港、沪港、沪日、沪美、福建高防等方向。

它的产品和 Linode、Vultr 这类普通 VPS 有本质区别：每台专线 VPS 分配 1 个独立入口 IP 和 1 个独立出口 IP。你用 SSH 或 RDP 连入口，在机器里跑业务程序，流量从出口 IP 发出去。普通机房 VPS 走的是公网路由，而 Mkcloud 的产品走专线通道，比如广港方向端内延迟只有 1~2ms，沪美方向约 124~134ms——这些是官方产品页标注的端内参考值，不是你到目标网站的全程耗时。

第三方测评对它的网络质量反馈比较一致：延迟和稳定性是主要好评点，广港线路的低延迟基本能跑出来，客服响应速度也被多次提到。它成立时间不长这点要心里有数，_evaluations_社区里对“跑路风险”的讨论一直存在，这属于所有新兴商家的通用风险。

## 买之前必须知道的五件事

这几条直接来自官网购物车页面和知识库，下单前不看清楚，后面容易出纠纷。

1. **必须国内实名**。所有专线产品都要求中国身份信息实名：个人用户要手机号、姓名、身份证号，企业用户要营业执照、法人身份证和对公账户。没有国内身份信息的话，这家买不了。
2. **省份白名单**。IPLC/IEPL 产品只允许一个省份的 IP 连入，下单时要在下拉框里选好所在省份，开通后可以自行修改。
3. **用途限制写得很硬**。官方明确禁止机场、回国等违规用途，所有专线产品采取省级白名单措施防滥用。出口 IP 不支持外部连入，也就是说这类产品不适合做公开网站、支付回调、邮件接收或游戏服务端——它给的是“你的服务器向外访问”这条路径。
4. **退款只认质量问题**。仅支持质量问题退款，而且要求工单里提交具体延迟、速度数据作为证据；开通后不支持更换到其他地域。
5. **IX 产品需要云厂前置**。深港、沪港等上云互联（IX）产品不挑连入省份，但必须通过云厂 BGP 网络接入——腾讯云、百度云国内全网、火山云华南、华为云华南这些在支持范围内，你需要自己先有一台支持范围内的云机做前置。阿里云国内全网目前暂不通。

另外它默认没有 SLA 承诺，也不提供快照备份。企业级用户对可用性有硬指标的，先走工单问清楚再下单。

5. **付款下单**：月付起步，有优惠码或优惠券的话在这一步填。

## 几个常见问题

**出口 IP 是原生 IP 吗？**
不是。官方明确说当前是服务器 IP，不保证原生、住宅、流媒体解锁或历史干净，独享 IP 也不承诺平台账号不被限制。做 TikTok、电商多账号的朋友对 IP 质量的期待要放在“独享+机房 IP”这个定位上。

**能当回国或机场用吗？**
不能，官方写明禁止，违规清退不退款。

**流量超了怎么办？**
计量套餐双向统计流量，超量后暂停，可自助购买流量重置，或提交工单补差价升级套餐。深港 IX 新售套餐是超量直接停机，跑大流量的业务盯着点用量。

**后期可以降配吗？**
可以，升降级都走工单，但降级到更低价套餐时差价不退。
